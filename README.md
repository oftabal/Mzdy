# OFTABAL – Mzdy

## Nahrání na GitHub

1. Otevřete repozitář `oftabal/Mzdy`.
2. Klikněte na **Add file → Upload files**.
3. Nahrajte **obsah této složky**, tedy:
   - `index.html`
   - `manifest.webmanifest`
   - `sw.js`
   - složky `css`, `js`, `icons`
4. Klikněte na **Commit changes**.

## Zapnutí GitHub Pages

1. Otevřete **Settings → Pages**.
2. V části **Build and deployment** nastavte:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
3. Klikněte na **Save**.

Aplikace bude na adrese:

https://oftabal.github.io/Mzdy/

## Přidání na plochu iPhonu

1. Otevřete výše uvedenou adresu v Safari.
2. Klepněte na Sdílet.
3. Zvolte **Přidat na plochu**.
